# Figures

This directory contains **public-safe, non-proprietary visualizations** for the research portfolio.

## Included

### Research diagrams

- [`research_architecture_v2.svg`](research_architecture_v2.svg) — conceptual system architecture, including the causal core, independent challenger modules, and validation governance.
- [`synthetic_wave_state_demo.svg`](synthetic_wave_state_demo.svg) — synthetic illustration of price, wave-state behavior, and generic volatility-risk windows. It is **not** production output.

### Current Cross-Market Examples

- [`btcusd_crypto_1h_current.png`](btcusd_crypto_1h_current.png) — **BTCUSD (CRYPTO), 1H.** Repeated lower-zone episodes during a sustained decline, followed by a visible wave recovery as price rebounds.
- [`qqq_nasdaq_4h_current.png`](qqq_nasdaq_4h_current.png) — **QQQ (NASDAQ ETF), 4H.** Alternating wave states and repeated extreme-zone visits across an advance, pullbacks, and a later decline with a rebound.
- [`nvda_nasdaq_4h_current.png`](nvda_nasdaq_4h_current.png) — **NVDA (NASDAQ), 4H.** Repeated upper- and lower-zone episodes, with numbered annotations and shaded intervals visible alongside the wave.
- [`gold_tvc_1h_current.png`](gold_tvc_1h_current.png) — **Gold (TVC), 1H.** Alternation between extreme regions and intermediate states during an advance, a subsequent decline, and rebounds.
- [`real_examples.md`](real_examples.md) — interpretation notes and disclosure boundaries for the current gallery.

The gallery order is BTC → QQQ → NVDA → Gold. The screenshots expose only visible chart output and illustrate behavior across different market contexts. They do not establish strategy profitability or cross-market statistical validity and are not trading recommendations.

Earlier screenshot files are retained for historical reference but are not used in the current gallery.

## Disclosure boundary

The figures intentionally omit:

- production formulas
- exact calibrated parameters
- Pine Script source code
- private AutoLab implementation
- raw private datasets
- execution-specific trading rules
- account or API information

Visualizations in this directory communicate **research design and interpretation**, not a recipe for reconstructing the proprietary implementation.
